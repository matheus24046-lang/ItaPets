# 🐾 ItaPets

Site institucional de um petshop, desenvolvido com HTML e CSS. O projeto apresenta a loja, seus produtos e uma página de contato para os clientes.

🔗 **Acesse o site:** https://jmatheus-dev.github.io/ItaPets/

---

## 📄 Páginas

| Página | Descrição |
|---|---|
| `index.html` | Página inicial com a apresentação do petshop |
| `produtos.html` | Catálogo de produtos disponíveis |
| `contato.html` | Informações e formulário de contato |

## 🛠️ Tecnologias utilizadas

- **HTML5** para a estrutura das páginas
- **CSS3** para a estilização e o layout

## 📁 Estrutura do projeto

```
ItaPets/
├── imagens/          # Imagens gerais do site
├── produtos/         # Imagens dos produtos
├── index.html        # Página inicial
├── produtos.html     # Página de produtos
├── contato.html      # Página de contato
├── style.css         # Folha de estilos
└── README.md
```

## 🚀 Como executar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/jmatheus-dev/ItaPets.git
   ```
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no seu navegador.

Não é necessário instalar nenhuma dependência.
